# Hospital Management System
Spring Boot 3 + Thymeleaf + Spring Data JPA + MySQL.

## Run
1. Install JDK 17+, Maven, MySQL.
2. Edit `src/main/resources/application.properties` (MySQL password).
3. `mvn spring-boot:run`
4. Open http://localhost:8080  — login: admin / admin123

The database `hospital_db` and its tables are created automatically (or run `schema.sql`).
